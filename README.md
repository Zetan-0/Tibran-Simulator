# Tibran-Simulator
Hello, this is a 2D sandbox grand strategy game written in Python, built on Pop!_OS, and will be scaled to include C# for performance.

Tibran-Simulator is a video game about controlling, creating, and conquering as a space empire to conquer other civilizations on a universal scale. The project is to include a storyline, wave based gameplay, and a sandbox-like set up similar to Stellaris or Galimulator.
